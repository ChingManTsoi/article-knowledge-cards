# Knowledge Cards

把一篇已给到手的文章（粘贴文本或本地 Markdown / PDF 文件）提炼成 5–8 张知识卡片：每张卡一个知识点，包含标题、核心知识、简明解释、例子或自测问题。

本 skill 只做"提炼"，不做"扩写"：不补充原文没有的信息，信息不足时宁可少出卡片。它不抓取网页、不导出 Anki、不做图形界面或图片卡片。

## 何时使用

- 用户粘贴一段文章 / 长文，要求做知识卡片、读书卡片、提炼要点、帮忙记住内容。
- 用户给出本地 `.md`、`.txt`、`.pdf` 路径，要求转换成卡片。
- 用户要求"用卡片形式"输出某篇已有文本。

不适用：只需逐段摘要或翻译；需要生成图片卡 / 思维导图；需要 Anki 或其它记忆软件格式；只给了网址（本 skill 不抓网页）。

## 输入处理

1. **粘贴文本**：直接用，不要求用户重发。
2. **本地文件**：用 `read_file` 读取（PDF 会自动提取文本层）。不要为读文件自行安装依赖或调用外部服务。
3. **无文本层的 PDF**（扫描件、图片型）：`read_file` 拿到空内容或乱码时，直接说明"无法提取到文本"，请用户提供文字版或可复制文本；**不要**根据文件名或标题猜测内容。
4. **超长文章**：先读完整个文本再开始选点。不要读一段就出卡——否则卡片会全部来自开头部分，中后段的重要结论被漏掉。
   - 读取结果里出现 `[... truncated]`、`(省略)`、行数上限之类的标记时，继续读剩余部分（`read_file` 递增 offset，或直接读原文件），直到拿到完整文本。基于残缺文本出的卡片一律作废，重做。
5. **语言与栏目标签**：输出语言优先跟随用户的提问语言；用户没指定语言时，才跟随原文语言。整篇统一，不中英混排。栏目标签、主线行、卡片序号同步切换：

   | 输入语言 | 主线行 | 卡片标题 | 三栏标签 |
   | --- | --- | --- | --- |
   | 中文 | `> 主线：…` | `### 卡片 1｜…` | `**核心知识**` `**简明解释**` `**例子或自测**` |
   | 英文 | `> Main line: …` | `### Card 1 \| …` | `**Core knowledge**` `**Concise explanation**` `**Example or self-check**` |

   术语保留其原语言写法：中文卡里写 `retrieval practice（提取练习）`，英文卡里保留原文专名。不要自造标签（如把 `Concise explanation` 写成 `Explanation`、把 `self-check` 写成 `self-test`）。

## 提炼流程

每一步都有完成标准，达不到就不要进入下一步。

1. **通读，列候选点**（内部草稿，不输出）。一句话一个候选点，并记下它在原文的出处（哪一段、哪句话）。
   - 完成标准：候选点数量多于目标卡片数；每个候选点都能指向原文的具体句子，而不是你的联想。
2. **合并同类，删除重复**。同一原理的不同表述、换词重述、同一结论的两次出现，合并成一张卡；例子不单独成卡，例子属于它支撑的那个知识点。
   - 完成标准：任意两张卡之间不再共享同一个结论。
3. **按价值筛到 5–8 个**。排序依据：信息量、可迁移性（能不能用在别处）、是否支撑全文主线。
   - 保留：核心机制、关键区分、反直觉结论、可执行方法、作者的主要论证。
   - 删除：背景铺垫、罗列式常识定义、修辞与情绪表达、作者个人轶事（除非它就是论据）、页面或操作界面细节。
4. **按模板逐卡写作**。四栏齐全，缺一栏就回原文换点。
5. **跑一遍末尾的质量检查表**，任何一条不过就修。

## 按体裁取舍

不同体裁的"重要知识"不同，按下表决定保留与舍弃：

| 体裁 | 抓什么 | 丢什么 | 典型张数 |
| --- | --- | --- | --- |
| 论文 / 研究报告 | 方法、机制、成立条件、关键数字 | 相关工作铺陈、实现细节、致谢与附录 | 6–8 |
| 议论文 / 随笔 | 核心主张、论证链、反直觉结论 | 修辞、纯轶事（除非它就是论据）、反复强调 | 5–7 |
| 技术文档 / 参考 | 概念区分、默认行为、易错点、字段语义 | 导航、样板示例、历史包袱 | 5–8 |
| 教程 / 操作指南 | 方法背后的原理、适用条件 | 逐步点击与命令（除非它本身就是要点） | 3–6，步骤不单独成卡 |
| 新闻 / 快讯合集 | 背后的技术或产品安排、关键数字与型号 | 纯日期、赛事、发布会流程 | 按可讲机制计数，常 2–6；一条机制都没有时直接说明该文不适合出知识卡片 |

## 卡片格式

先写一行全文主线（不超过两行，说明这篇文章在论证什么），再按原文论述顺序输出卡片。

```markdown
> 主线：<一句话概括全文在论证什么>

### 卡片 1｜<标题：直接说出这个知识点>

**核心知识**：<一句话结论，脱离上下文也能独立成立>

**简明解释**：<2–4 句，说清它是什么 / 为什么成立 / 怎么起作用>

**例子或自测**：<原文中的例子（可压缩改写），或一个只用本卡内容就能回答的自测问题>
```

四栏的具体规则：

| 栏目 | 要求 | 反例 |
| --- | --- | --- |
| 标题 | 说清一个知识点本身，能当索引；标题里只承载一个机制 | "要点一"、"核心观点"；"A 能带来 X，而 B 会带来 Y" 这类串两个机制的标题 |
| 核心知识 | 一句陈述句，有主语和结论，不写"本文认为" | "作者讲了记忆的重要性" |
| 简明解释 | 只用原文信息，可压缩、可改写、可解释术语的字面含义，不新增事实、数据、因果、建议 | 补一句"研究表明能提升 30%"（原文没有） |
| 例子或自测 | 例子必须来自原文；原文没例子时写自测问题，问题要能用本卡内容答上 | 编一个原文没有的案例；问一个要靠卡外知识才能回答的问题 |

## 数量规则

- 常规 5–8 张。原文信息量大且彼此独立时取 8；信息适度时取 5–6。
- **信息不足就少出**：原文只支撑 3 个知识点时输出 3 张，并在开头写明"原文主要讲一件事，只提炼出 3 张卡片"。
- **严禁凑数**：把一个知识点的两个方面拆成两张卡、同一结论换说法重复出现、加入"延伸思考"这类原文没有的卡片，都算违反本 skill。
- 超过 8 个同等重要的点：把相邻、可合并的点并成一张（卡内仍只解释一个统一机制），总量不超过 8。
- **用户指定张数时按用户的数**（如"只保留 3 张""出 10 张"）：以用户要求为准，并在开头一句话说明取舍依据；用户只要张数没给理由时，仍按上面的价值排序保留。

## 输出

- 默认把卡片直接写在对话里（Markdown），不建文件、不建目录。
- 用户要求保存时，写到源文件同目录，命名 `<源文件名>-cards.md`；粘贴文本则命名 `knowledge-cards.md`。
- 输出末尾不追加"总结""我的建议"等原文之外的内容。

## 质量检查表

发出前逐条核对：

- [ ] 每张卡只有一个知识点，标题里没有把两个机制串起来
- [ ] 四栏齐全，没有空栏、没有"略"
- [ ] 卡片之间无重复结论
- [ ] 每个论断都能在原文找到依据；没有新增数字、人名、案例、因果、建议
- [ ] 主线行、卡片标题、三栏标签与正文语言一致，全篇没有中英混排或自造标签
- [ ] 数过 `### 卡片` / `### Card` 的实际出现次数，与开头声明的张数一致
- [ ] 数量在 5–8 之间，或已在开头说明为何少于 5
- [ ] 被删掉的是背景、修辞、常识，而不是论据
- [ ] 卡片顺序与原文论述顺序一致，便于回查

## 常见问题

- **只读到开头就出卡**：长文必须先通读，否则后半篇的核心结论会整体丢失；卡片应能对应文章的各个主要部分。
- **把"重要性"当知识点**：写"X 很重要"没有信息量；要写 X 是什么、为什么重要、在什么条件下成立。
- **拆卡凑数**：一张卡讲"机制"、另一张讲"机制的效果"，通常应合成一张卡；效果属于解释的一部分。
- **术语照抄不解释**：英文术语保留原文，但解释要让人看懂它在本文里指什么。
- **PDF 表格、公式、脚注丢失**：提取文本时这些内容可能损坏。关键论证依赖表格或公式时，明确提示该处可能不完整，不要去"补全"它。
- **栏目标签跟着正文语言混掉**：英文正文配中文标签（或反过来）是最常见的退化。整篇只用一套标签，见"输入处理"第 5 条。
- **基于截断文本出卡**：读取工具只给了开头和结尾时，卡片会全是开头的内容。见到省略标记就继续读完。
- **标题串两个机制**：标题需要"而""并且""以及"再接一个独立机制时，拆成两张卡，或把次要的那个删掉。
- **用户给的是网址**：本 skill 不抓网页，请用户粘贴正文或提供本地文件。
- **在卡片外加评论**：不写读后感、扩展思考、行动建议，除非用户另外要求。

## 示例（节选，只演示格式）

原文片段：*"睡眠并非大脑的关机状态。在慢波睡眠阶段，海马体会把白天形成的记忆反复重放给新皮层，这一过程被称为记忆巩固。因此熬夜学习后的记忆保留率显著低于睡够之后再复习。"*

> 主线：睡眠通过重放机制把白天的记忆固化到新皮层，所以睡够比多学一会儿更能保住记忆。

### 卡片 1｜慢波睡眠中的记忆重放

**核心知识**：慢波睡眠期间，海马体把白天形成的记忆重放给新皮层，完成记忆巩固。

**简明解释**：睡眠不是关机状态，巩固发生在海马体向新皮层重放记忆的过程中；记忆是在睡着时被固定下来的，不是在醒着时被固定下来的。

**例子或自测**：原文例子——熬夜学习后的记忆保留率低于睡够之后再复习。

### 卡片 2｜压缩睡眠会直接降低记忆保留

**核心知识**：牺牲睡眠换取学习时间，会降低记忆保留率。

**简明解释**：既然巩固依赖睡眠中的重放，压缩睡眠就等于压缩巩固环节；多出的学习时间无法抵消这一损失。

**例子或自测**：自测——如果重放发生在慢波睡眠，把复习安排在睡前一小时而不是清晨，预期效果会怎样？

> 该片段只支撑 2 个知识点，因此只出 2 张卡，不补足到 5 张。
