# knowledge-cards

一个开源的 Agent Skill：把你手上的文章（粘贴的文本，或本地 Markdown / txt / PDF 文件）提炼成 5–8 张知识卡片。每张卡只讲一个知识点，包含标题、核心知识、简明解释、例子或自测问题。

纯指令型 skill，没有脚本、没有依赖、不需要 API key。

## 1. 解决什么问题

读完一篇长文后，"记住真正重要的那几点"通常靠两种方式，都不理想：

- **自己划重点**：耗时，而且容易抄下开头几段、漏掉后半篇的核心结论。
- **让模型直接总结**：输出不可预期——经常逐段复述、把同一结论换三种说法、补齐原文没有的数字和案例、或为了凑够张数硬拆知识点。

这个 skill 把"提炼"变成一条可核对的流程：先通读全文，列出能指回原文句子的候选点，合并重复，按信息量／可迁移性／是否支撑主线筛到 5–8 个，再按固定四栏写作，最后过一遍质量检查表。它明确禁止扩写——每个论断都要能在原文找到依据，信息不足时宁可少出卡片。

## 2. 主要功能

| 能力 | 具体表现 |
| --- | --- |
| 输入 | 粘贴的文本；本地 `.md` / `.txt` / `.pdf`（PDF 需有文本层） |
| 输出 | 一行全文主线 + 5–8 张卡，每张四栏：标题、核心知识、简明解释、例子或自测 |
| 体裁判别 | 论文 / 议论文随笔 / 技术文档 / 教程操作指南 / 新闻快讯各有取舍规则与典型张数（论文 6–8，随笔 5–7，技术文档 5–8，教程 3–6，快讯按可讲机制计 2–6） |
| 去重合并 | 同一原理的换词重述合并成一张；例子不单独成卡，归属它所支撑的知识点 |
| 不凑数 | 信息不足就少于 5 张，并在开头写明原因；严禁拆卡、换说法重复 |
| 不编造 | 不新增数字、人名、案例、因果、建议；PDF 表格/公式提取损坏时明确提示，而不去补全 |
| 语言 | 跟随你的提问语言；你没指定时跟随原文语言，整篇不中英混排（中/英两套栏目标签） |
| 输出位置 | 默认直接写在对话里；你说"保存"时写到源文件同目录，命名 `<源文件名>-cards.md`（粘贴文本则为 `knowledge-cards.md`） |

**不支持**：网页抓取（只给网址不行）、Anki 或其它记忆软件导出、图形界面、图片卡片、思维导图。

## 3. 安装方法

skill 就是一个目录，放进你所使用 Agent 的 skills 目录即可：

```bash
# Codex
cp -r knowledge-cards ~/.codex/skills/
# Claude Code
cp -r knowledge-cards ~/.claude/skills/
# Hermes Agent
cp -r knowledge-cards ~/.hermes/skills/
```

凡是遵循 `SKILL.md + agents/openai.yaml` 约定的 Agent，都可以直接使用这个目录，不需要改配置。

目录结构：

```
knowledge-cards/
├── SKILL.md            # 规则与流程（Agent 读取的唯一入口）
└── agents/
    └── openai.yaml     # UI 元数据：显示名、简短描述、默认调用提示
```

可选校验（需要已安装 `skill-creator` 技能）：

```bash
python3 <skill-creator>/scripts/quick_validate.py knowledge-cards
# Skill is valid!
```

## 4. 使用方法

装好后直接用自然语言提要求，skill 的描述会让 Agent 自动选中它：

```
用 knowledge-cards 把这篇文章做成知识卡片：
<粘贴正文>
```

```
把 ~/Documents/papers/attention.pdf 转成知识卡片
```

```
读一下 README.md，做成知识卡片，保存成文件
```

Codex 下也可以显式调用：`Use $knowledge-cards to turn this article into 5-8 knowledge cards.`

几条实用的使用约定：

- **给正文或文件，不要给网址**：本 skill 不抓网页。
- **扫描版 PDF 不行**：没有文本层时它会直说提取不到，请你提供文字版，不会靠文件名猜内容。
- **想少出几张就直说**：可以说"只保留最关键的 3 张"。
- **要文件就说"保存"**：否则卡片只在对话里，不会写盘。

## 5. 输入输出示例

**输入**（粘贴的文章片段）：

> 睡眠并非大脑的关机状态。在慢波睡眠阶段，海马体会把白天形成的记忆反复重放给新皮层，这一过程被称为记忆巩固。因此熬夜学习后的记忆保留率显著低于睡够之后再复习。

**输出**：

> 主线：睡眠通过重放机制把白天的记忆固化到新皮层，所以睡够比多学一会儿更能保住记忆。

### 卡片 1｜慢波睡眠中的记忆重放

**核心知识**：慢波睡眠期间，海马体把白天形成的记忆重放给新皮层，完成记忆巩固。

**简明解释**：睡眠不是关机状态，巩固发生在海马体向新皮层重放记忆的过程中；记忆是在睡着时被固定下来的，不是在醒着时被固定下来的。

**例子或自测**：原文例子——熬夜学习后的记忆保留率低于睡够之后再复习。

### 卡片 2｜压缩睡眠会直接降低记忆保留

**核心知识**：牺牲睡眠换取学习时间，会降低记忆保留率。

**简明解释**：既然巩固依赖睡眠中的重放，压缩睡眠就等于压缩巩固环节；多出的学习时间无法抵消这一损失。

**例子或自测**：自测——如果重放发生在慢波睡眠，把复习安排在睡前一小时而不是清晨，预期效果会怎样？

> 该片段只支撑 2 个知识点，因此只出 2 张卡，不补足到 5 张。

换成文件输入时，输出格式相同；若你要求保存，会得到：

```
~/Documents/papers/attention-cards.md
```

## 已知限制

- PDF 的表格、公式、脚注在文本提取时可能错位或丢失，此时卡片只用正文可确认的表述，并提示该处可能不完整。
- 资讯快讯类文章往往只有事件、没有机制，卡片会明显少于 5 张；一条机制都提炼不出时，它会直接说明该文不适合出知识卡片。
